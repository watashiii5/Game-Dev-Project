# GAME DEV

A 2D pixel-art game built in Unity 6 (6000.0.37f1).

## Web Deployment

This project is automatically built and deployed to **GitHub Pages** via GitHub Actions on every push to `main`.

**Live URL:** https://watashiii5.github.io/Game-Dev-Project/

### How it works

1. Push to `main` triggers the GitHub Actions workflow
2. Unity builds the project for WebGL using GameCI
3. The build is deployed to GitHub Pages automatically
